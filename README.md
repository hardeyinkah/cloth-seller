# Cloth Seller

An online fashion store with Women and Men collections, where customers place their orders through WhatsApp. Built for shoppers in Nigeria, with prices in naira.

## Features

- **Women and Men collections** with product cards and prices in NGN
- **Sale badges:** Hot Sale, Bestseller, New Release, Light Deals and Trends, each in its own colour
- **Flash Deals** section
- **Shop the Look:** complete a featured outfit in a few taps
- **Stories:** campaign and seasonal content
- **Product detail view, wishlist and shopping bag**
- **Order on WhatsApp** checkout, plus a live chat button
- **Country and language selector**
- **Store locator** and newsletter sign-up
- Responsive layout that works on phones

## Built with

- HTML, CSS and JavaScript (no framework)
- Deployed on Vercel

## Run it locally

Open `index.html` in a browser, or use the Live Server extension in VS Code or Cursor.
